3.1 a) O parâmetro formal é o valor passado na assinatura da função, exemplo em uma função qualquer "double calcular(double valor)", a variável 'valor' seria o parâmetro formal, enquanto
os argumentos são definidos formalmente e na prática como os valores passados entre os parênteses do parâmetro. No exemplo do código "distancia_euclidiana", não existem parâmetros formais, e 
os argumentos são os próprios valores passados para os parênteses das funções da biblioteca cmath.

b) Quando uma função é chamada, um stack frame é criado e empilhado na call stack, guardando parâmetros, variáveis locais e o endereço de retorno. Ao atingir o return, o valor de retorno 
é entregue ao chamador (normalmente via registrador), o stack frame é desempilhado e o endereço de retorno é usado para que a execução continue na instrução seguinte à chamada.

3.2

codigo_corrigido.cpp

#include <iostream>
#include <cmath>

double calcularMedia(double a, double b) {
    double media =  (a + b) / 2;
    return media;
}

int main() {
    double x = 10.0, y = 6.0;
    double resultado = calcularMedia(x, y);

    std::cout << "Raiz da media: " << std::sqrt(resultado) << std::endl;    
    return 0;
}

Explicação: O erro mais visível é o erro de tipagem (type error) da função "calcularMedia", que foi atribuído inicialmente como "void" e declarou um retorno "double". Para corrigir, basta 
trocar o nome "void" por "double". O outro possível erro, se deve a compilação no sistema Linux, porém no Windows o único erro é o de tipagem mesmo.
